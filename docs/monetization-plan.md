# BloxBGM Monetization Plan

Domain: `bloxbgm.com`
Launch scope: searchable Roblox music ID table plus scenario playlists.

## Phase 0: Build Trust First

- Separate `verified`, `candidate`, and `unavailable` IDs in data and UI.
- Keep source and source access date for every listed ID.
- Do not show ad-heavy layouts before the first indexation and content-quality pass.

## Phase 1: Low-Risk Monetization

- Display ads after Search Console confirms indexation and early impressions.
- Use one top-of-page ad slot and one mid-content slot on `/codes` only.
- Keep playlist pages lighter so they can earn backlinks and repeat visits.

## Phase 2: Labeled Sponsorship

- Sponsored playlist placements for Roblox creators or game communities.
- Private-server or community-server recommendation blocks where relevant.
- All paid placements must be labeled as sponsored.

## Phase 3: Productized Assets

- Premium downloadable playlist packs for creators.
- Creator partnership pages built around specific play styles.
- Lightweight data/API licensing only after the verification pipeline is reliable.

## Guardrails

- No deceptive copy buttons.
- No autoplay audio.
- No fake "working" labels.
- No copyrighted media hosting; BloxBGM lists IDs and context only.
- If an ID fails verification, mark it `unavailable` instead of deleting the history.
